# TUKIO PRO — Site Web v2 (Light Mode)

Plateforme digitale premium · E-Voting · Collecte · Billetterie Corporate · Événements Privés

## Structure

```
tukio-pro/
├── home/                     → Page d'accueil
├── e-voting/                 → Module E-Voting
├── crowdfunding/             → Module Collecte
├── corporate-ticketing/      → Billetterie Corporate
├── private-ticketing/        → Événements Privés
└── images/                   → Illustrations SVG
```

## Design

- **Mode** : Light (fond #FFFDF5 / blanc)
- **Accent** : Or #BCA402
- **Typographies** : Posterama 1913 (titres) · Montserrat (corps)
- **Icônes** : SVG inline colorés (sans emojis)

## Démarrage

Ouvrir `home/index.html` dans un navigateur moderne.
